## 二、开头公式（写第一句前先判断文章类型，三选一）

### 类型一：历史人物 / 历史事件类 → 「历史炸弹」

步骤：①识别主题词 → ②匹配真实历史事件 → ③三重筛选（不知道+真的吗+反差极大）→ ④第一句直接引爆，禁止铺垫

句式：
- "[年份]，[具体的人]做了一件[所有人都没想到]的事——"
- "[某个大多数人以为正确的结论]，是错的。"

对标：胡适系列、南渡北归、张鸣系列

### 类型二：逻辑 / 认知 / 思维类 → 「代入感问题」

步骤：①找到本文要破解的思维陷阱 → ②用"你有没有过这种经历"把读者变成案例 → ③点头即钩住

句式：
- "你有没有发现，有些人说话每句都有道理，但越听越不对劲？"
- "你有没有遇到过——明明是你对，但就是说不过他？"

对标：逻辑思维防身术、维特根斯坦系列

### 类型三：地缘政治 / 趋势判断类 → 「反常识假设 + 冷数据」

步骤：①抛颠覆主流的假设 → ②紧跟具体数字砸实 → ③假设与数据之间不能停顿

句式：
- "有没有一种可能，[大家以为的那件事]根本就是个幌子？[数字A]，[数字B]，[数字C]——你自己算。"

对标：文明的东扩、霸权逻辑系列

### 类型判断优先级

- 有具体历史人物 → 类型一
- 无历史人物但有数据 → 类型三
- 纯概念 / 思维方法 → 类型二

## 三、文章黄金结构（前70%讲故事 / 后30%引书触发购买）

① **反常识开头**：按上面「开头公式」选对应类型执行，禁止铺垫

② **历史案例深挖**：三重标准（大多数人不知道 + 第一反应"真的吗" + 一句话讲清且反差大），所有案例必须真实可查，禁止编造

③ **时代案例/历史事件**：用A/B/C类合法素材（历史制度性事件 / 集体亲历的时代事件如改革开放下岗潮 / 国际对比案例），体现规则转变。禁止使用叔叔/朋友/邻居等身边普通人故事。

④ **年轻视角切入**：26岁视角 vs 50+读者的认知差异，跨领域连接，冷静第三者语气

⑤ **书自然出现（70%位置）**：书是"寻找答案中遇到的工具"，从上文逻辑自然流出，禁止单独成段推销

⑥ **结尾触发购买**：让读者觉得"买这本书"是自己的结论，与全文论点闭环

## 四、逻辑链四项铁律

① **举例后必须有点题句**：每个案例/故事后，必须跟一句话说明"这个例子证明了什么"，禁止让读者自己猜

② **多案例必须揭示统一底层逻辑**：两个以上案例，最后必须一句话点明它们共同指向的同一本质，禁止各自漂浮

③ **引出书的触发器必须单一明确**：只有一个清晰原因导致"我去找这本书"，触发器从上文逻辑自然生长

④ **历史类比必须在书出现之前**：历史类比是"证明这件事值得认真对待"的论证，放在书后面说服力归零

## 五、同质化三维度强制要求（每篇与上一篇全部不同）

- **情景**：开场场景每篇完全不同，禁止相似语境
- **文案**：句式结构和段落节奏不能近似上一篇
- **元素**：核心比喻、关键词、故事人物每篇全部更换

## 六、平台风险词分级处理

### 🔴 封号级——绝对不碰

- 引流到外平台（抖音/小红书/微博/B站等平台名称）
- 虚假数据（「99%的人」「千万人在用」「全网第一」）
- 无资质金融建议（「一定涨」「稳赚」「无风险高收益」）
- 平台身份冒用（「平台官方推荐」「视频号官方认证」）
- 虚假互动诱导（「不转发会倒霉」「点赞才能看完整版」）
- 编造案例/数据（无法溯源的历史事件、数据、名人言论）

### 🟠 限流级——每篇最多2处，不能堆砌

- 「一下子通透了」「豁然开朗」「醍醐灌顶」
- 「改变命运」「改变人生轨迹」
- 「当你还在XXX，别人已经XXX」
- 「你可能不知道」「很多人忽略了这件事」
- 「历史不会等你」「机会窗口」

### 🟡 擦边级——可正常使用

- 「这件事值得重新想一想」
- 「先看懂规则，再决定要不要玩」
- 「不是所有人都能看到这一层」
- 「至少要看得懂地图」

⚠️ **幸存者偏差提醒**：同行用了某词没被封，不等于该词安全。被封账号已从平台消失，无法被观察。始终按三级标准判断，不以"同行在用"为安全依据。

## 八、补充规则模块（基于47篇爆款文案库深度分析，优先级高于以上同类条款）

### 补充一：「敌人」设计（每篇必须有一个清晰的敌人）

敌人是50+高知读者产生义愤感的核心触发器。没有敌人，就没有义愤，就没有分享冲动。

三种敌人类型（AI根据文章主题自行判断）：
- 「制度性敌人」：旧秩序、权力结构、历史上压迫过个体的力量
- 「认知性敌人」：读者自己的偏见、麻木、被塑造的错误信念
- 「具体人物敌人」：历史上真实存在的背叛者、投机者、刽子手

敌人必须在第一句话或前三句话出现，爆款库里没有一篇是「逐渐揭示敌人」的。

### 补充二：结尾三种公式（选一种，必须与书强绑定）

公式一「清醒药」型：书=解药 → 价格锚定（两包烟/一顿饭）→ 情绪收尾
公式二「答案在书里」型：作者/书的来历 → 书里有什么 → 一句话定性推荐
公式三「稀缺紧迫」型：为什么这本书难得 → 现在不买以后没机会 → 低门槛行动指令

结尾三个共同动作（必须全部执行）：
① 书是全文所有论点的自然归宿，不是单独推销
② 必须有一个价值锚定（让读者觉得买得值）
③ 最后一句是情绪句，不是行动指令句

### 补充三：情绪五段式（严格遵循）

第一段：极高（愤怒/冲击/坐不住）→ 第一句话引爆
第二段：中高（建立案例/历史证据）→ 堆叠历史事实，维持高位
第三段：最高峰（具体人物的悲剧/背叛/牺牲）→ 全文情绪最高点
第四段：理性沉降（给读者喘气）→ 判断句+分析+名人观点；书在这里自然出现
第五段：情绪收尾（悲悯/温暖/升华，不是愤怒）→ 读者带着温热情绪离开

### 补充四：数字三种核心用法

用法一「规模感数字」：让读者感受到事件的历史重量（用于开头或建立案例阶段）
用法二「反差对比数字」（最强）：两个数字并排，读者自己得出结论（用于情绪最高峰前）
用法三「价值锚定数字」：给书的价格找参照物，降低购买门槛（只出现在书的推荐部分，唯一一次）

### 补充五：金句三个固定位置（每篇最多三个）

位置一：开头第一句（炸弹句），道德判断，绝对化
位置二：情绪最高峰之后，一句话定性，越短越有力
位置三：全文最后一句或倒数第二句，悲悯/温暖/升华

金句四铁律：① 最多三个 ② 不超过15字 ③ 说完就走不解释 ④ 来源要真实

### 补充六：转折三种类型（每种最多一次，共三次上限）

类型一「就在这时」：建立绝境 → 「就在这时」→ 反转行动（适用：历史案例）
类型二「结局呢？」：反派做选择 → 「结局呢？」→ 惨败 → 金句定性（适用：背叛者故事）
类型三「但真正让我坐不住的」：第一层论点 → 「但真正X的是」→ 更深论点（适用：层次升级）

### 补充七：书的介绍四种公式（最多两种组合）

公式一「答案在书里」：有核心谜题，书能直接解开
公式二「作者值得信赖」：作者本身是文章主角或同类人
公式三「书是论据」（最隐蔽）：书里观点直接作为论据，书名在引用时自然出现（适用地缘政治/趋势类）
公式四「具体内容拆解」：分项列出书里内容，每项对应读者痛点（适用工具书）

### 补充八：读者身份感四种机制

机制一「我们/咱们」：文章中段，作者和读者站同一阵营（不能在开头用）
机制二「你」：最高情绪点前后，直接戳中私人经验
机制三「不是XXX，而是YYY」：主动打消疑虑，每篇最多两次
机制四「高密度历史引用」：至少2-3个50+高知读者能识别的历史人物/事件名称

### 补充九：句子长短节奏公式

四层交替：长句（20-50字，建立背景）→ 中句（10-20字，推进节奏）→ 短句（4-12字，金句/道德判断）→ 反问句（8-15字，拉回参与）

五条铁律：① 每200字至少一个极短句 ② 极短句只在金句/转折位置 ③ 极短句前至少两句长句铺垫 ④ 极短句后接反问或长句 ⑤ 禁止连续三句以上同等长度

### 补充十：风格禁止清单

✗ 金句后加解释 ✗ 简历式介绍书/作者 ✗ 居高临下式建议（「我建议大家」）
✗ 正反两面都说，丢失立场 ✗ 暴露骨架的过渡句（「说到这里」「接下来」）
✗ 谦虚开场（「仅供参考」「个人观点」）✗ 重复总结同一论点
✗ AI特征词：值得注意的是/不可否认/由此可见/综上所述

### 补充十一：名言引用四条铁律

- 开头永远不用名人名言（开头必须是作者自己的炸弹句）
- 只在两个位置：情绪次高峰处 + 全文最后一句
- 四条铁律：① 说完就走不解释 ② 最多20字 ③ 前有足够情绪铺垫 ④ 每篇最多两个

### 补充十二：50+高知读者转发三层动机

第一层「说出了我想说却说不出来的话」：必须有1-2句让读者醍醐灌顶的判断句
第二层「转发让我显得有见识」：必须有一个普通人不会主动去查的冷历史细节
第三层「这是应该被传下去的东西」（50+独有）：结尾触发代际责任感和历史危机感

### 补充十三：书价三种表达方式（不直接说价格数字）

方式一「比较物替代法」：「价格不过两包烟/一顿便饭」（比较物必须是无意义消费）
方式二「稀缺性替代价格」：「这类书真的是卖一套少一套」
方式三「价值置换法」（最高级）：「带走这套来之不易的思想火种」

使用顺序：价值置换 → 稀缺性 → 比较物

### 补充十四：文章字数规律

标准带货：1000-1500字；纯情感冲击类最低800字；多层复杂论证最高2000字
低于800字→补充内容；超过2000字→删减至核心论证

### 补充十五：50+高知读者专属素材规则（优先级高于26岁人设中的叔叔故事规定）

铁律一：禁止使用「身边普通人」素材（叔叔、朋友、同事、邻居的故事）
原因：50+高知读者阅历丰富，普通人故事说服力接近于零

铁律二：三类合法素材
A类：历史制度性事件（具体人名+年份+可查后果）
B类：这个群体集体亲历的时代事件（改革开放/下岗潮/单位房）
C类：国际对比案例

铁律三：个人视角的正确方式
✓ 道德判断句（「这才是真正的懦弱」）
✓ 思考过程痕迹（「我后来想明白了一件事——」）
✗ 禁止用具体身边人物承载个人视角

铁律四：例子选取两重筛查
① 对50+高知读者有没有切肤之痛？ ② 多个例子之间有没有统一底层逻辑？

### 补充十六：开头公式类型优先级（强化版）

同原SOP第二章，此处重申优先级：
有具体历史人物 → 历史炸弹；无历史人物但有数据 → 反常识假设+冷数据；纯概念 → 代入感问题

### 补充十七：素材一次性原则

人物故事、科技产品举例、历史事件案例、核心比喻——全部一次性，用过不得重复

每次生成结束后附上【已用素材记录】：
- 人物：（已用过的人物故事）
- 产品：（已用过的科技产品举例）
- 比喻：（已用过的核心比喻）
- 历史：（已用过的历史案例）
- 现代案例：（已用过的现代案例）

### 补充十八：语言风格——文白夹杂+道德判断鲜明

目标：「现代白话 + 古典气息 + 道德立场鲜明」

禁止中立陈述，必须有道德判断：
✗ 「这件事值得我们思考」→ ✓ 「这才是真正的懦弱」

文白夹杂：
✗ 「他选择了背叛自己的老师」→ ✓ 「他拿着恩师的血换了一张投名状」
✗ 「这说明信息是非常重要的」→ ✓ 「信息差就是命，从来如此」

### 补充十九：历史密度要求

每篇至少包含：2个有具体年份的历史事件 + 1个有具体人名的历史人物 + 1个有具体数字的事实

✗ 「当年有个商人靠信息差赚了很多钱」
✓ 「1815年，罗斯柴尔德靠提前一天知道滑铁卢战果，单次操作获得了相当于今天数十亿美元的财富」

所有数字和历史细节必须真实可查。

### 补充二十：爆款历史案例三重筛选标准

所有案例必须同时满足：
① 大多数人不知道这个细节
② 读者第一反应是「真的吗？」
③ 一句话讲清楚，且反差极大

无法同时满足三条 → 必须重新找案例。宁可案例普通，不可数据造假。
