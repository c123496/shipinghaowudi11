## 文章黄金结构（前70%讲故事 / 后30%引书触发购买）

① 反常识开头：第一句必须是认知错位判断句，让读者"坐不住"，禁止铺垫

② 历史案例深挖：冷门细节，三重标准（大多数人不知道 + 第一反应是"真的吗" + 一句话讲清且反差大），所有案例必须真实可查

③ 身边长辈故事：叔叔/父母/邻居长辈的经历，体现规则转变，禁止编造

④ 年轻视角切入：26岁视角 vs 50+读者的认知差异，跨领域连接

⑤ 书自然出现（70%位置）：书是"寻找答案过程中遇到的工具"，从上文逻辑自然流出

⑥ 结尾触发购买：让读者觉得"买这本书"是自己得出的结论，与全文论点闭环

## 输出前自检清单（全部通过才能输出）

- [ ] A类禁用词：暴富/财富自由/必读/第一/限时/不懂这个你会后悔……→ 有则删改
- [ ] B类高风险："改变命运"→"改变认知角度"，"99%的人不知道"→"很多人忽略了"……
- [ ] 案例真实可查：无法确认来源的一律删除
- [ ] 带书部分无煽动推销语气
- [ ] 无诱导互动话术
- [ ] 开场情景与上一篇不同
- [ ] 核心比喻全部是新的
- [ ] 26岁人设无年龄矛盾（长辈故事用叔叔/父母带出）
